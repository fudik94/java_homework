# Java Homework Project

## Project Overview
This project contains 22 Java challenges organized in folders by challenge number under `src/`.
Challenges are completed one by one based on instructions provided by the user.

## Structure
- `src/challenge1/` — Challenge 1 tasks
- `src/challenge2/` — Challenge 2 tasks
- `src/challenge3/` — Challenge 3 tasks
- `src/challengeN/` — and so on up to challenge 22

## Workflow
- User provides challenge instructions from a presentation, one at a time
- Each challenge gets its own folder: `src/challengeN/`
- Each task within a challenge gets its own `.java` file

## Code Style
- Write code at **junior level** — simple, straightforward, no over-engineering
- Occasionally add very short inline comments (2-4 words) to make the code feel naturally written by a student
- No complex abstractions, keep it simple and readable
- Commit messages: user will specify each time
