# Java Academy Project
 

## Project Structure

- All source code is in the `src` folder.  
- There are five folders inside `src`, one for each challenge:  
  - `challenge1` — contains files for the first challenge (currently only this folder has files).  
  - `challenge2`  
  - `challenge3`  
  - `challenge4`  
  - `challenge5`  

## Notes

- Each Java file corresponds to a lesson exercise.  
- You can run each class individually to test the code.
